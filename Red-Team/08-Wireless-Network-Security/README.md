# Section 8 — Network Hacking: Securing Wireless Access

**Track:** Red Team | **Type:** Theory / defensive implications of wireless attacks  
**Status:** Theory documented; no Section 8 practical test or screenshot has been completed or claimed.

This section explains how wireless security weaknesses are assessed by authorised testers and how network owners can reduce exposure. The focus is WEP, WPA/WPA2, Wi-Fi Protected Setup (WPS), password strength, and WPA3.
